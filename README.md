# 🤝 CampusTeam

A modern **Team Matcher** web application that helps students find the perfect teammates for hackathons, college projects, startups, and competitions. CampusTeam makes collaboration easy by allowing users to showcase their skills, discover talented peers, and build strong teams—all from one platform.

---

## 🚀 Features

- 👨‍💻 Create a personal team profile
- 🔍 Search teammates by skills
- 🤝 Find collaborators for projects and hackathons
- 🎯 Mention required roles and technologies
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🎨 Modern and clean UI
- 📋 Browse available team requests

---
